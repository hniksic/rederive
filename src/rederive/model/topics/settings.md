# Settings

A setting is changed on its Manage or Options screen, or by assigning to its name:
`Precision := Approximate`.

## Simplification

| Command | What it sets |
|---|---|
| Manage | how expressions are kept, and how they are simplified |
| Manage Branch | which of several roots a radical stands for: Principal, Real or Any |
| Manage Exponential | whether exponentials are collected or expanded |
| Manage Logarithm | whether logarithms are collected or expanded |
| Manage Trigonometry | angle sums, multiple angles, powers, and degrees or radians |
| Manage Ordering | the order the variables are taken in, the main one first |

Exponential, Logarithm and Trigonometry each take Auto, Collect or Expand. The Angle
setting of Manage Trigonometry changes only how angles in answers are shown: functions
take [radians](help:functions/elementary) either way.

## Numbers, input and display

| Command | What it sets |
|---|---|
| Options | how numbers are read, worked out and printed |
| Options Precision | exact, approximate or mixed arithmetic, and its digit count |
| Options Notation | the style answers are printed in, and how many digits |
| Options Radix | the number system input and output are written in |
| Options Input | one-letter or whole-word names, case sensitivity, arrow key mode |
| Options Output | built-up or compressed display, and which multiplication sign is printed |
| Options Mute | whether an invalid keypress beeps |
| Options Color | the colors of the menu bands and of the work area |
| Options Defaults | put every setting that a worksheet saves back to its factory default, recording each change |
