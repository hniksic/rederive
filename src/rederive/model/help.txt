The help document. Each subject starts with a %topic line carrying, between
bars, the option the HELP menu line shows, the line the Help Menu lists, and
the title every page of the subject is headed with. Everything after it is the
text, in blocks separated by blank lines; a block is kept whole on a page
wherever it fits on one. Lines are written for eighty columns and wrapped to
whatever the window turns out to be, so a table row that has to break keeps
its own indent. The one subject whose body is the %settings directive is
generated from the settings themselves and is written nowhere.

%topic Basics | the Basics of Rederive | Rederive Basics

Rederive is a worksheet rather than a calculator. An expression is entered
with the Author command and numbered as it arrives, and nothing at all is
worked out until a command is aimed at it. Every answer becomes a new numbered
expression of its own, so a session reads down the screen as a record of what
was asked and what came of it. Nothing a command computes replaces what it was
computed from.

Driving a menu:
  Space, Tab            move the highlight to the next option
  Backspace, Shift-Tab  move it back
  Enter                 run the highlighted option
  a capital letter      run the option that letter names, from anywhere
  Esc                   leave a submenu, or abandon the command being answered

Every option carries exactly one capital letter, and that letter invokes it
wherever the highlight happens to be standing. Usually it is the first letter:
A authors, S simplifies, Q quits. Where two options of one menu would want the
same letter the capital moves along the word instead, which is why the command
menu reads soLve, moVe and approX.

A first session:
  press A, type x^3 - x, press Enter
  press F for Factor, then Enter at each question it asks
  press S for Simplify, then Enter

Every question a command asks comes up with an answer already on it, so a
command is usually carried through by pressing Enter as many times as it asks.

Naming an expression:
  the arrow keys   move the highlight from one expression to the next
  #3               expression 3, wherever it now stands on the screen
  Jump             move the highlight to a numbered expression at once

A command that wants an expression opens with the label of the highlighted one
already on its line, so Enter alone answers it. Moving the highlight while
that line is up takes the label along with it. The label is the safer of the
two ways to answer: it goes on meaning the same expression after a Remove or a
moVe has changed what stands where.

Using the mouse:
  a menu option    click it to run it, as its own capital letter does
  an expression    click it to highlight it, again to go one part deeper
  a value          click it to set it, on an Options screen or any question
  the wheel        scrolls the history; with Shift held, sideways over an
                   expression too wide for the pane
  another window   click in it to make it the active one

Every gesture stands for a key, so nothing here needs the mouse and nothing is
reachable only with it. Text swept out with the button held down is the
terminal's own selection rather than an expression, and Ctrl-C copies that
while it stands. A sweep over the line being typed marks out a stretch of it
instead, which Ctrl-C copies and Ctrl-X takes off the line.

Exact before approximate:
  Simplify   work an expression out exactly, however long the answer
  approX     work it out as a number, to the precision now set
  Options Precision   which of the two Simplify does

An answer is kept exact wherever it can be, so Simplify of 1/3 + 1/6 is 1/2
and not 0.5, and the square root of 2 stays a square root. approX is how a
number is asked for.

Not guessing:
  Declare Variable   give a variable a value, or a domain to simplify over
  Declare Function   define a function of your own

A simplification that would only be right for some values of a variable waits
until something says which values those are. Until then the expression stands
as it is, which is the honest answer rather than a wrong one.

Files, screen and settings:
  Transfer Save    write the worksheet out
  Transfer Load    read one back in
  Transfer Clear   start again with nothing
  Options          how numbers are read, worked out and printed
  Manage           which transformations the simplifier applies
  Window           split the screen, so two parts of one session show at once
  Help             this help
  Quit             leave, after asking whether that was meant

%topic Editing | line Editing commands | Line Editing Commands

The keys below apply to every line the program reads: the Author line, the
lines the Declare and Calculus commands read, the value lines of Manage
Substitute, the operand lines of Build and the lines that name a file. F6 is
about an expression, so it applies to the lines that take one and not to a line
collecting a variable, a file name or an annotation.

Special key commands:
  F1           display this help; the line being typed is kept
  F6           hand the sideways arrow keys to the line, or to the highlight
  Ctrl-C       copy what is marked out, or the highlighted expression
  Ctrl-X       cut what is marked out on the line
  Ctrl-V       paste what was copied onto the line
  Ins          switch between making room for a character and typing over one
  Tab          on a line naming a file, complete the name and open the list
  Enter        accept the line
  Ctrl-Enter   accept it, and simplify the expression the command enters
  Esc          abandon the command; on an open list of names, close the list

Cursor movement commands:
  Left, Right  one character along the line
  Home         to the start of the line
  End          to the end of it

Text selection commands:
  Shift-Left, Shift-Right   mark out one more character, one fewer
  Shift-Home, Shift-End     mark out to the start of the line, to the end
  the mouse                 sweep over the line with the button held down

Ctrl-C copies what is marked out and Ctrl-X takes it off the line, keeping the
copy for Ctrl-V. With nothing marked out, Ctrl-C copies the highlighted
expression instead and Ctrl-X says there is nothing to cut, cutting being
about the line and nothing else. The label a command offers on its line comes
up selected so that typing replaces it, but that is the command's offering
rather than a selection of yours, and neither key acts on it.

Text deletion commands:
  Backspace    delete the character before the cursor
  Delete       delete the character under it
  Ctrl-W       delete the word before the cursor
  Ctrl-U       delete the line before the cursor
  Ctrl-K       delete the line from the cursor on
  Ctrl-Y       put back what the last deletion took out
  Alt-Y        after Ctrl-Y, put back an earlier deletion instead

What was deleted stands until the program is left, so Ctrl-Y is also how a
piece of one line is carried onto another.

The status line says which of the two typing modes is in force: Ovr stands
there while a character typed types over what is already at the cursor, and
nothing stands there while it makes room for itself. Lin stands beside it while
the sideways arrow keys belong to the line rather than to the highlight. Both
words are about the line being typed, so neither stands there without one.

Expression highlighting commands. These go on working while a line is being
typed, a line of text having nothing vertical to do with them, which is what
makes it possible to move onto an expression and then copy it onto the line. The
variable line Factor and Expand read is the one line that holds the highlight
still:
  Up, Down            the previous, the next expression
  PgUp, PgDn          a paneful back, a paneful forward
  Ctrl-Home, Ctrl-End the first, the last expression
  Ctrl-PgUp, Ctrl-PgDn  the same two
  Ctrl-Left, Ctrl-Right scroll sideways over an expression wider than the pane

Sub-expression highlighting commands. Press F6, or set Options Input Use to
Subexpression, and the sideways keys walk into the highlighted expression
instead of along the line:
  Right   into the expression, or on to the part beside the one highlighted
  Left    back to the part before it
  Down    deeper into the highlighted part
  Up      back out to the part holding it
  Home    the first part alongside
  End     the last part alongside

What is highlighted is what a command acts on, so a subexpression can be
factored, approximated or substituted for on its own without the expression
around it being disturbed.

A click walks the same tree from the other end. The first one highlights the
expression it lands on and each one after it goes a part deeper towards what
the pointer is over, so a term of a long sum is reached without having to hit
the single character it is drawn as. A click on a part of the expression
holding the one highlighted - the operator between two terms belongs to the sum
and to neither term - goes back out to it, and a click on the number in front
of the expression highlights the whole of it again. The arrow key mode does not
apply: a click reaches a subexpression whichever way F6 has left the keys.

Entering Greek letters, special constants and operators:
  Alt-A  alpha     Alt-B  beta      Alt-D  delta     Alt-N  epsilon
  Alt-H  theta     Alt-M  mu        Alt-P  pi        Alt-S  sigma
  Alt-T  tau       Alt-F  phi       Alt-O  omega     Alt-G  Gamma
  Alt-Q  the square root sign       Alt-0  infinity
  Alt-E  the base of natural logarithms, #e
  Alt-I  the square root of -1, #i
  Alt-minus  the plus-or-minus sign
  Alt-V  the subscript operator, SUB

Every one of them can be spelled out instead - alpha, pi, inf, sqrt, #e, #i -
and the spelling is what the program prints back either way, so nothing has to
be entered with an Alt key. Alt-minus needs a terminal that reports a modified
key; where it does not, plus-or-minus is written +-.

%topic Functions | Functions and constants | Functions, Constants, and Operators

A name is a function where it is followed by an argument list and a variable
where it is not. Case is ignored unless Options Input Case says otherwise, so
SIN, Sin and sin are one function. Nothing here computes when it is authored:
what is entered is entered as written, and Simplify or approX is what works it
out.

Constants:
  pi                 the ratio of a circle's circumference to its diameter
  #e                 the base of the natural logarithms
  #i                 the square root of -1
  inf                infinity; -inf is the other end
  deg                one degree, so 90 deg is a right angle
  euler_gamma        Euler's constant
  true, false        the two truth values
  ?                  an unknown value

Operators:
  u + v, u - v       sum and difference
  u*v, u v           product; a space or nothing between multiplies too
  u/v                quotient
  u^v                power
  u!                 factorial
  u%                 u divided by a hundred
  -u                 negation
  u.v                dot product of two vectors, or product of two matrices
  u`                 transpose of a matrix
  u SUB v            element v of the vector u, or a subscripted name
  u +- v             both u + v and u - v at once
  x := u             give the variable x the value u
  f(x) := u          define a function
  x :epsilon Real    declare what x ranges over

Relational operators:
  u = v, u /= v      equal, not equal
  u < v, u <= v      less than, not greater than
  u > v, u >= v      greater than, not less than

Boolean operators and functions:
  NOT u              negation
  u AND v, u OR v    conjunction, disjunction
  u XOR v            exclusive disjunction
  u IMP v            implication
  TRUTH_TABLE(p, q, ..., u, ...)  the table of u over the variables named

Solving equations and relations:
  SOLVE(u, x)        solve u for x, which is what the soLve command writes
  LHS(u), RHS(u)     the sides of a relation, or of each relation in a vector

Exponential and logarithmic functions:
  EXP(z)             #e raised to z
  LN(z)              the natural logarithm
  LOG(z), LOG(z, w)  the natural logarithm, and the logarithm to base w
  SQRT(z)            the square root

Trigonometric functions:
  SIN(z), COS(z), TAN(z)     sine, cosine, tangent
  COT(z), SEC(z), CSC(z)     cotangent, secant, cosecant

Inverse trigonometric functions:
  ASIN(z), ACOS(z), ATAN(z)  the inverses of the first three
  ATAN(y, x)                 the angle of the point (x, y), by quadrant
  ACOT(z), ASEC(z), ACSC(z)  the inverses of the other three

The angle mode set by Manage Trigonometry Angle says whether an argument is
read, and an answer written, in radians or in degrees.

Hyperbolic functions:
  SINH(z), COSH(z), TANH(z)  hyperbolic sine, cosine, tangent
  COTH(z), SECH(z), CSCH(z)  hyperbolic cotangent, secant, cosecant

Inverse hyperbolic functions:
  ASINH(z), ACOSH(z), ATANH(z), ACOTH(z), ASECH(z), ACSCH(z)

Piecewise continuous functions:
  SIGN(z)            -1, 0 or 1 by the sign of z; SIGN(0) is +-1
  STEP(z)            0 below zero and 1 above it
  CHI(a, z, b)       1 between a and b, 0 outside them
  IF(test, u, v)     u where the test holds, v where it does not
  FLOOR(u), FLOOR(u, v)  the greatest integer not above u, or not above u/v
  MOD(u, v)          the remainder of u on division by v
  MODS(u, v)         the same, taken symmetrically about zero
  MAX(...), MIN(...) the largest, the smallest of the arguments

Complex variable functions:
  RE(z), IM(z)       the real and the imaginary part
  ABS(z)             the magnitude, and so the absolute value of a real z
  CONJ(z)            the complex conjugate
  PHASE(z)           the angle z makes with the positive real axis

Probability and statistical functions:
  COMB(n, k)         the number of combinations of n things taken k at a time
  PERM(n, k)         the number of permutations
  AVERAGE(...)       the mean of the arguments, or of a vector's elements
  RMS(...)           the root mean square
  VAR(...)           the variance
  STDEV(...)         the standard deviation
  NORMAL(z), NORMAL(z, m, s)  the normal distribution, standard or not

Error and special functions:
  ERF(z), ERFC(z)    the error function and its complement
  GAMMA(z)           the gamma function
  ZETA(z)            the Riemann zeta function

Number theory functions:
  GCD(...), LCM(...) the greatest common divisor, the least common multiple
  PRIME(n)           whether n is prime
  NEXT_PRIME(n)      the least prime above n
  QUOTIENT(u, v)     how many times v goes into u
  REMAINDER(u, v)    what is left of u when v has gone into it
  POLY_GCD(u, v)     the greatest common divisor of two polynomials

Expression decomposition functions:
  NUMERATOR(u), DENOMINATOR(u)   the two halves of a quotient
  TERMS(u)           what u is written as the sum of, as a vector
  FACTORS(u)         what u is written as the product of, as a vector
  VARIABLES(u)       the free variables of u, the main one first
  NUMBER(u)          whether u simplifies to a number
  APPROX(u), APPROX(u, n)  u as a number, at the set precision or at n digits

Calculus functions:
  DIF(u, x), DIF(u, x, n)      the derivative, to the first or the nth order
  INT(u, x)                    the indefinite integral
  INT(u, x, a, b)              the definite integral between a and b
  LIM(u, x, a), LIM(u, x, a, d)  the limit at a; d says from which side
  SUM(u, k, a, b)              the sum over k from a to b
  PRODUCT(u, k, a, b)          the product over the same range
  TAYLOR(u, x, a, n)           the Taylor polynomial of degree n about a

Generating vectors and matrices:
  VECTOR(u, k, ...)  u at each value k takes, as a vector
  SELECT(u, k, ...)  the values of k for which the test u holds
  ITERATES(u, x, a), ITERATES(u, x, a, n)  a, u(a), u(u(a)), as a vector
  ITERATE(u, x, a), ITERATE(u, x, a, n)    the last element of that sequence
  IDENTITY_MATRIX(n) the n by n identity matrix

The values an index runs over are said in four ways, and VECTOR, SELECT and
ITERATES all read them alike: a count on its own, a first and a last, a first
and a last and a step, or a vector of the values themselves.

Vector manipulation functions:
  DIMENSION(v)               how many elements v has
  ELEMENT(v, i)              element i, counting from one
  ELEMENT(m, i, j)           element j of row i of a matrix
  APPEND(v, w, ...)          the elements of each, run into one vector
  REVERSE_VECTOR(v)          the elements in the other order
  INSERT_ELEMENT(u, v, n)    v with u written in before its nth element
  DELETE_ELEMENT(v, n)       v with its nth element gone
  REPLACE_ELEMENT(u, v, n)   v with u where its nth element was

A matrix is a vector of its rows, so every one of these takes a matrix and
works on rows.

Vector and matrix operations:
  u.v                the dot product, or the matrix product
  CROSS(u, v)        the cross product of two three-element vectors
  DET(m)             the determinant
  TRACE(m)           the trace
  ROW_REDUCE(m), ROW_REDUCE(m, b)  the reduced echelon form
  CHARPOLY(m, z)     the characteristic polynomial in z
  EIGENVALUES(m, z)  its zeros, written as equations in z

Vector calculus:
  GRAD(u), GRAD(u, a)          the gradient of a scalar field
  DIV(v), DIV(v, a)            the divergence of a vector field
  CURL(v), CURL(v, a)          the curl
  LAPLACIAN(u), LAPLACIAN(u, a)  the divergence of the gradient
  POTENTIAL(v), POTENTIAL(v, p)  a scalar whose gradient is v
  VECTOR_POTENTIAL(v), VECTOR_POTENTIAL(v, p)  a vector whose curl is v
Each of the six takes an optional vector of coordinates, so the same function
serves cartesian, cylindrical and spherical coordinates.

%topic Algebra | Algebra window commands | Algebra Window Command Menu

Move the highlight with Space or Tab and press Enter, or type the one capital
letter the option carries. Esc leaves a submenu without choosing anything, and
abandons a command that has begun to ask questions.

Author        enter an expression as the next numbered entry, unsimplified
Build         put an expression together from ones already on the screen
Calculus      write a calculus expression for Simplify to work out
  Differentiate  the derivative, to any order; a negative order integrates
  Integrate      the integral, definite between two limits or indefinite
  Limit          the limit at a point, approached from the left, right or both
  Product        the product of an expression over a range of an index
  Sum            the sum over the same range
  Taylor         the Taylor polynomial about a point, to a given degree
  Vector         the vector of an expression over a range of an index

Declare       give a name a meaning
  Function       define a function of any number of variables
  Variable       give a variable a value, or a domain to simplify over
  Matrix         enter a matrix element by element
  vectoR         enter a vector element by element

Help          this help

Manage        how expressions are kept, and how they are simplified
  Annotate       change what the status line says an expression came from
  Branch         which of several roots a radical stands for
  Exponential    whether exponentials are collected or expanded
  Logarithm      whether logarithms are collected or expanded
  Ordering       the order the variables are taken in, the main one first
  Renumber       number the expressions again from one
  Substitute     put a value in place of a variable, or of a subexpression
  Trigonometry   angle sums, multiple angles, powers, and degrees or radians

Options       how numbers are read, worked out and printed

  Notation       the style answers are printed in, and how many digits

Plot          draw the highlighted expression in a plot window

Transfer Load Utility reads a file of definitions without numbering what it
reads, which is how a library of functions is brought into a session. The
utility files written for the original Derive can be read this way.

Transfer Save writes a worksheet in this program's own format, and also writes
a highlighted expression out as C, Python, Rust or Julia source.

A plot window is a window of the desktop rather than a part of this screen,
and it is closed the way any other window is. The picture is navigated with the
mouse: the wheel zooms about the pointer, the left button drags the view, the
right button sweeps out a rectangle to zoom to, and a double click centres the
view where it lands.

Plot window key commands:
  Home or 0    the framing a fresh window opens with
  A            frame every curve that is showing
  + and -      zoom in and out about the middle of the view
  arrows       move the view a quarter window; move the marker, while tracing
  Backspace    back to where the view was; Shift-Backspace forward again
  T or F3      trace: a marker rides a curve and the status bar reads it out
  L and G      the legend and the grid
  Ctrl-C       copy the picture, or the traced point, to the clipboard
  Ctrl-S       save the picture, the sampled points, or a drawing of it

Algebra window key commands:
  F1           the next window; help, while a line is being typed
  Shift-F1     the previous window
  F2           bring the next of this window's overlays to the top
  Shift-F2     the previous one
  F6           hand the sideways arrow keys to the line, or to the highlight
  Ctrl-C       copy what is selected, or the highlighted expression
  Ctrl-X       cut what is selected on the line being typed
  Ctrl-V       paste what was copied onto the line being typed
  Esc          abandon the question being asked; stop a running computation

A command that reaches the engine says on the message line how long it has
been running, and Esc stops it. What it had computed is thrown away and the
worksheet stands as it did.
