The help document. Each subject starts with a %topic line carrying, between
bars, the option the HELP menu line shows, the line the Help Menu lists, and
the title every page of the subject is headed with. Everything after it is the
text, in blocks separated by blank lines; a block is kept whole on a page
wherever it fits on one. Lines are written for eighty columns and wrapped to
whatever the window turns out to be, so a table row that has to break keeps
its own indent. The one subject whose body is the %settings directive is
generated from the settings themselves and is written nowhere.

%topic Basics | the Basics of Rederive | Rederive Basics

Rederive is a worksheet rather than a calculator. An expression is entered
with the Author command and numbered as it arrives, and nothing at all is
worked out until a command is aimed at it. Every answer becomes a new numbered
expression of its own, so a session reads down the screen as a record of what
was asked and what came of it.

Driving a menu:
  Space, Tab            move the highlight to the next option
  Backspace, Shift-Tab  move it back
  Enter                 run the highlighted option
  a capital letter      run the option that letter names, from anywhere
  Esc                   leave a submenu, or abandon the command being answered

Every option has one capital letter, usually the first: A authors, S
simplifies, Q quits. When the first letter is already taken, a later one is
capitalized instead: soLve, moVe, approX.

A first session:
  press A, type x^3 - x, press Enter
  press F for Factor, then Enter at each question it asks
  press S for Simplify, then Enter

Every question comes with a default answer filled in, so a command is usually
completed by pressing Enter at each question.

Naming an expression:
  the arrow keys   move the highlight from one expression to the next
  #3               expression 3, named by its number
  Jump             move the highlight to a numbered expression at once

A command that asks for an expression starts with the label of the highlighted
one already on its line, so Enter alone answers it. Moving the highlight
updates the label. A label like #3 keeps meaning the same expression even
after Remove or moVe has moved things around on the screen.

The mouse works everywhere: menu options, Options screens, windows and
expressions can all be clicked. Clicking an expression highlights it, and each
further click goes one part deeper into it. The wheel scrolls the history;
with Shift held, sideways over an expression too wide for the pane.

Every gesture stands for a key, so nothing here needs the mouse and nothing is
reachable only with it. Dragging selects text, not expressions: Ctrl-C copies
the selection, and on the line being typed Ctrl-X cuts it.

Exact before approximate:
  Simplify   work an expression out exactly, however long the answer
  approX     work it out as a number, to the precision now set
  Options Precision   whether Simplify answers exactly or numerically

An answer is kept exact wherever it can be, so Simplify of 1/3 + 1/6 is 1/2
and not 0.5, and the square root of 2 stays a square root. approX is how a
number is asked for.

Declarations:
  Declare Variable   give a variable a value, or a domain to simplify over
  Declare Function   define a function of your own

A simplification that is only right for some values of a variable waits for a
declaration: LN(x^2 - x) - LN(x) becomes LN(x - 1) only once x is declared
positive. Until then the expression is left as it is.

Files, screen and settings:
  Transfer Save    write the worksheet out
  Transfer Load    read one back in
  Transfer Clear   start again with nothing
  Options          how numbers are read, worked out and printed
  Manage           which transformations the simplifier applies
  Window           split the screen, so two parts of one session show at once
  Help             this help
  Quit             leave the program, after asking for confirmation

%topic Editing | line Editing commands | Line Editing Commands

The keys below apply to every line the program reads, from the Author line to
a line naming a file.

Special key commands:
  F1           display this help; the line being typed is kept
  F6           switch the Left and Right keys between the line and the
               highlight; only on lines that take an expression
  Ctrl-C       copy what is selected, or the highlighted expression
  Ctrl-X       cut what is selected on the line
  Ctrl-V       paste what was copied onto the line
  Ins          switch between inserting characters and typing over them
  Tab          on a line naming a file, complete the name and list the matches
  Enter        accept the line
  Ctrl-Enter   accept it, and simplify the expression the command enters
  Esc          abandon the command; on an open list of names, close the list

Cursor movement commands:
  Left, Right  one character along the line
  Home         to the start of the line
  End          to the end of it

Text selection commands:
  Shift-Left, Shift-Right   select one more character, one fewer
  Shift-Home, Shift-End     select to the start of the line, to the end
  the mouse                 drag over the line with the button held down

With nothing selected, Ctrl-C copies the highlighted expression instead. The
label a command puts on its line comes up selected so that typing replaces it;
Ctrl-C and Ctrl-X leave it alone.

Text deletion commands:
  Backspace    delete the character before the cursor
  Delete       delete the character under it
  Ctrl-W       delete the word before the cursor
  Ctrl-U       delete everything before the cursor
  Ctrl-K       delete the line from the cursor on
  Ctrl-Y       put back what the last deletion took out
  Alt-Y        after Ctrl-Y, put back an earlier deletion instead

Deleted text is kept for the whole session, so a piece of one line can be
deleted and put back on another.

The status line shows Ovr while typing overwrites the character at the cursor,
and Lin while the Left and Right keys belong to the line rather than to the
highlight.

Expression highlighting commands. These keep working while a line is being
typed, so an expression can be highlighted and then copied onto the line; only
the variable line of Factor and Expand keeps the highlight where it is:
  Up, Down            the previous, the next expression
  PgUp, PgDn          a screenful back, a screenful forward
  Ctrl-Home, Ctrl-End the first, the last expression
  Ctrl-PgUp, Ctrl-PgDn  the same as Ctrl-Home and Ctrl-End
  Ctrl-Left, Ctrl-Right scroll sideways over an expression wider than the pane
  <, >                  the same, where the Ctrl keys never reach the program

Sub-expression highlighting commands. Press F6, or set Options Input Use to
Subexpression, and the sideways keys walk into the highlighted expression
instead of along the line:
  Right   into the expression, or on to the part beside the one highlighted
  Left    back to the part before it
  Down    deeper into the highlighted part
  Up      back out to the part holding it
  Home    the first part at this depth
  End     the last part at this depth

What is highlighted is what a command acts on, so a subexpression can be
factored, approximated or substituted for on its own without the expression
around it being disturbed.

Clicks reach subexpressions too. The first click highlights the whole
expression, and each further click goes one part deeper towards what the
pointer is over, so a term of a long sum is reached without aiming at a single
character. A click just outside the highlighted part - on the operator joining
it to its neighbour, say - goes back out one level, and a click on the number
in front of the expression highlights the whole of it again. Clicks work the
same in either arrow-key mode.

Entering Greek letters, special constants and operators:
  Alt-A  alpha     Alt-B  beta      Alt-D  delta     Alt-N  epsilon
  Alt-H  theta     Alt-M  mu        Alt-P  pi        Alt-S  sigma
  Alt-T  tau       Alt-F  phi       Alt-O  omega     Alt-G  Gamma
  Alt-Q  the square root sign       Alt-0  infinity
  Alt-E  the base of natural logarithms, #e
  Alt-I  the square root of -1, #i
  Alt-minus  the plus-or-minus sign
  Alt-V  the subscript operator, SUB

Every one of them can be spelled out instead - alpha, pi, inf, sqrt, #e, #i -
and the spelling is what the program prints back either way, so nothing has to
be entered with an Alt key. If Alt-minus does not work in your terminal, type
+- instead.

%topic Functions | Functions and constants | Functions, Constants, and Operators

A name is a function where it is followed by an argument list and a variable
where it is not. Case is ignored unless Options Input Case says otherwise, so
SIN, Sin and sin are one function. Entering SIN(0.5) computes nothing;
Simplify or approX works it out.

Constants:
  pi                 the ratio of a circle's circumference to its diameter
  #e                 the base of the natural logarithms
  #i                 the square root of -1
  inf                infinity; -inf is negative infinity
  deg                one degree, so 90 deg is a right angle
  euler_gamma        Euler's constant
  true, false        the two truth values
  ?                  an unknown value, written in answers that have none

Operators:
  u + v, u - v       sum and difference
  u*v, u v           product; x y and 3x multiply too
  u/v                quotient
  u^v                power
  u!                 factorial
  u%                 u divided by a hundred
  -u                 negation
  u.v                dot product of two vectors, or product of two matrices
  u`                 transpose of a matrix
  u SUB v            element v of the vector u, or a subscripted name
  u +- v             both u + v and u - v at once
  x := u             give the variable x the value u
  f(x) := u          define a function
  x :epsilon Real    declare what x ranges over; :epsilon is typed as
                     written, or as :∈

Relational operators:
  u = v, u /= v      equal, not equal
  u < v, u <= v      less than, less than or equal
  u > v, u >= v      greater than, greater than or equal

Boolean operators and functions:
  NOT u              negation
  u AND v, u OR v    conjunction, disjunction
  u XOR v            exclusive disjunction
  u IMP v            implication
  TRUTH_TABLE(p, q, ..., u, ...)  the truth table of the expressions u over
                                  the variables named before them

Solving equations and relations:
  SOLVE(u, x)        solve u for x; the soLve command writes this for you
  LHS(u), RHS(u)     the sides of a relation, or of each relation in a vector

Exponential and logarithmic functions:
  EXP(z)             #e raised to z
  LN(z)              the natural logarithm
  LOG(z), LOG(z, w)  the natural logarithm, and the logarithm to base w
  SQRT(z)            the square root

Trigonometric functions:
  SIN(z), COS(z), TAN(z)     sine, cosine, tangent
  COT(z), SEC(z), CSC(z)     cotangent, secant, cosecant

Inverse trigonometric functions:
  ASIN(z), ACOS(z), ATAN(z)  the inverses of the first three
  ATAN(y, x)                 the angle of the point (x, y), quadrant included
  ACOT(z), ASEC(z), ACSC(z)  the inverses of the other three

The angle mode set by Manage Trigonometry Angle says whether an argument is
read, and an answer written, in radians or in degrees.

Hyperbolic functions:
  SINH(z), COSH(z), TANH(z)  hyperbolic sine, cosine, tangent
  COTH(z), SECH(z), CSCH(z)  hyperbolic cotangent, secant, cosecant

Inverse hyperbolic functions:
  ASINH(z), ACOSH(z), ATANH(z), ACOTH(z), ASECH(z), ACSCH(z)

Piecewise continuous functions:
  SIGN(z)            -1, 0 or 1 by the sign of z; SIGN(0) is +-1
  STEP(z)            0 below zero and 1 above it
  CHI(a, z, b)       1 between a and b, 0 outside them
  IF(test, u, v)     u where the test holds, v where it does not
  FLOOR(u), FLOOR(u, v)  the greatest integer not above u, or not above u/v
  MOD(u, v)          the remainder of u on division by v
  MODS(u, v)         the same, taken symmetrically about zero
  MAX(...), MIN(...) the largest, the smallest of the arguments

Complex variable functions:
  RE(z), IM(z)       the real and the imaginary part
  ABS(z)             the magnitude, and so the absolute value of a real z
  CONJ(z)            the complex conjugate
  PHASE(z)           the angle z makes with the positive real axis

Probability and statistical functions:
  COMB(n, k)         the number of combinations of n things taken k at a time
  PERM(n, k)         the number of permutations
  AVERAGE(...)       the mean of the arguments, or of a vector's elements
  RMS(...)           the root mean square
  VAR(...)           the variance
  STDEV(...)         the standard deviation
  NORMAL(z), NORMAL(z, m, s)  the cumulative normal distribution

Error and special functions:
  ERF(z), ERFC(z)    the error function and its complement
  GAMMA(z)           the gamma function
  ZETA(z)            the Riemann zeta function

Number theory functions:
  GCD(...), LCM(...) the greatest common divisor, the least common multiple
  PRIME(n)           whether n is prime
  NEXT_PRIME(n)      the least prime above n
  QUOTIENT(u, v)     the integer quotient of u by v
  REMAINDER(u, v)    the remainder of u divided by v
  POLY_GCD(u, v)     the greatest common divisor of two polynomials

Expression decomposition functions:
  NUMERATOR(u), DENOMINATOR(u)   the top and the bottom of a fraction
  TERMS(u)           the terms of the sum u, as a vector
  FACTORS(u)         the factors of the product u, as a vector
  VARIABLES(u)       the free variables of u, the main one first
  NUMBER(u)          whether u simplifies to a number
  APPROX(u), APPROX(u, n)  u as a number, at the set precision or at n digits

Calculus functions:
  DIF(u, x), DIF(u, x, n)      the derivative, to the first or the nth order
  INT(u, x)                    the indefinite integral
  INT(u, x, a, b)              the definite integral between a and b
  LIM(u, x, a), LIM(u, x, a, d)  the limit at a; d > 0 from the right,
                                 d < 0 from the left; an a written in x
                                 substitutes instead of approaching
  SUM(u, k, a, b)              the sum over k from a to b
  PRODUCT(u, k, a, b)          the product over the same range
  TAYLOR(u, x, a, n)           the Taylor polynomial of degree n about a

Generating vectors and matrices:
  VECTOR(u, k, ...)  u at each value k takes, as a vector
  SELECT(u, k, ...)  the values of k for which the test u holds
  ITERATES(u, x, a), ITERATES(u, x, a, n)  a, u(a), u(u(a)), as a vector
  ITERATE(u, x, a), ITERATE(u, x, a, n)    the last element of that sequence
  IDENTITY_MATRIX(n) the n by n identity matrix

The values an index runs over can be given in four ways, and VECTOR, SELECT
and ITERATES all read them alike: a count on its own, a first and a last, a
first and a last and a step, or a vector of the values themselves.

Vector manipulation functions:
  DIMENSION(v)               how many elements v has
  ELEMENT(v, i)              element i, counting from one
  ELEMENT(m, i, j)           element j of row i of a matrix
  APPEND(v, w, ...)          the elements of each, joined into one vector
  REVERSE_VECTOR(v)          the elements in the other order
  INSERT_ELEMENT(u, v, n)    v with u written in before its nth element
  DELETE_ELEMENT(v, n)       v with its nth element gone
  REPLACE_ELEMENT(u, v, n)   v with u where its nth element was

A matrix is a vector of its rows, so every one of these takes a matrix and
works on rows.

Vector and matrix operations:
  u.v                the dot product, or the matrix product
  CROSS(u, v)        the cross product of two three-element vectors
  DET(m)             the determinant
  TRACE(m)           the trace
  ROW_REDUCE(m), ROW_REDUCE(m, b)  the reduced echelon form
  CHARPOLY(m, z)     the characteristic polynomial in z
  EIGENVALUES(m, z)  the eigenvalues of m, as equations in z

Vector calculus:
  GRAD(u), GRAD(u, a)          the gradient of a scalar field
  DIV(v), DIV(v, a)            the divergence of a vector field
  CURL(v), CURL(v, a)          the curl
  LAPLACIAN(u), LAPLACIAN(u, a)  the divergence of the gradient
  POTENTIAL(v), POTENTIAL(v, p)  a scalar whose gradient is v
  VECTOR_POTENTIAL(v), VECTOR_POTENTIAL(v, p)  a vector whose curl is v
Each of the six takes an optional vector of coordinates, so the same function
serves cartesian, cylindrical and spherical coordinates.

%topic Plot | Plotting expressions | Plotting Expressions

Plot draws the highlighted expression in a plot window:

Plot          draw in the most recently used plot window, opening one if needed
New           draw in a new window; later plots then go to it

The expression itself decides what kind of picture it makes, and with it which
of the two kinds of window it opens.

Expressions that open a 2D window:
  one variable, or none    a curve: SIN(x)/x, x^2 - 1, 3
  u = v                    the curve where the two sides are equal
  an inequality            the area where it holds: x^2 + y^2 < 9
  [u, v]                   a parametric curve: [3SIN(3t), 3SIN(4t)]
  [u, v, w] and longer     a curve for each: [x, x^2, x^3]
  [a, b] of numbers        a point; a vector of pairs draws them all

A pair of expressions makes a parametric curve, a pair of plain numbers a
point. To draw two curves together, Plot each expression in turn.

Expressions that open a 3D window:
  two variables            a surface: 1/(9 + x^2 + y^2)
  z = f(x, y)              a surface, z on the vertical axis
  a vector of either form  a surface for each, in one picture

Plotting an expression again replaces its old curve rather than adding one.
An expression in three or more variables cannot be plotted. The axes take
their names from the expression's own variables.

A plot window is an ordinary window of the desktop, with buttons and fields
along its top edge and a menu on right click.

Driving a 2D window with the mouse:
  wheel                 zoom about the pointer; Ctrl only x, Shift only y
  drag                  move the view
  right drag            mark a rectangle to zoom into
  double click          centre the view there
  click on a curve      trace it (see below)
  click a legend entry  hide that plot, or show it again
  right click           the window's menu

The menu also acts on the plot the click was over: remove it, or join a data
plot's points and change their size.

2D window keys:
  Home or 0    back to the starting view
  A            fit everything drawn into the view
  + and -      zoom in and out
  arrows       move the view
  Backspace    the previous view; Shift-Backspace forward again
  T or F3      trace on and off
  G and L      show or hide the grid and the legend
  Del          remove every plot
  Ctrl-C       copy the picture; while tracing, the marked point
  Ctrl-S       save the picture to a file
  Q            close the window

Set range... on the menu lets you type the four bounds of the view, as
expressions: -π is a valid bound. A fresh window shows -5 to 5 with the same
scale on both axes, so a circle is round. After A fits everything in, the two
scales may differ; the 1:1 button or Home makes them equal again. A plot drawn
entirely outside the current view is fitted into it automatically.

The polar button switches the window to polar coordinates: every curve is then
drawn as r = f(θ), with its variable as the angle. A parametric or polar curve
is first drawn for parameter values from -π to π; type other bounds into the
fields at the top of the window to change that.

Trace follows a curve with a marker and shows the coordinates under it. On an
ordinary curve the marker follows the pointer; the keys move it too:
  left, right    along the curve; faster with Shift
  up, down       onto another curve
  Tab            to the next root, maximum, minimum or intersection with
                 another curve; Shift-Tab to the previous one
  Enter          add the marked point to the worksheet as a new expression
  Ctrl-C         copy the marked point
  Esc            stop tracing

The points Tab finds are exact enough to calculate with. Where the curve has
no value, like SIN(x)/x at x = 0, tracing shows that too.

In a 3D window the mouse and keys move only the camera:
  drag         turn the picture; Shift-drag slides it
  wheel        nearer and further
  arrows       turn a step at a time
  Home or 0    back to the starting view
  1, 2, 3      look straight at the xy, xz or yz plane
  R            spin slowly; R again stops
  M            draw the surfaces as wire mesh, or shaded
  B            show or hide the box around the surfaces
  X            show or hide the numbers and names along the box edges
  L            show or hide the legend
  Del          remove every surface
  Ctrl-C, Ctrl-S, Q   as in a 2D window

The surfaces are computed over the domain given in the fields at the top, on a
grid of the given fineness; changing either recomputes them. The view...
button shows the plotted region and the camera as numbers you can edit; its
Autoscale z button returns to the automatic height after you have typed one.
A surface running off to infinity has its spike cut short, so that the rest of
the shape stays visible.

Ctrl-S saves a PNG image or, from a 2D window, an SVG drawing that scales in
print. Copies and saved files use dark lines on a white background, ready for
printing, and include the legend.

Options Plot sets the defaults for new plots: the grid of a surface, wire or
shaded, and whether data points are joined and how large they are drawn.
Changing one of these in a plot window changes the default too, and the
defaults are remembered between sessions.
